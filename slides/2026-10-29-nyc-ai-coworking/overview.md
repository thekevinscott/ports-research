# I asked an agent to port my codebase

<div class="big-steps">
  <div><strong>The codebase</strong><span>gbnf, a string manipulation library for GBNF grammars. Two implementations, written by hand: Python, 1,305 lines, and TypeScript, 1,129 lines. Language-agnostic tests.</span></div>
  <div><strong>Why smaller scales</strong><span>Lots of talk about porting at scale. I'm interested in reproducible ports: you maintain an SDK in several languages, or an open source library, and want one reference library that spawns the others.</span></div>
  <div><strong>So I ran an experiment</strong><span>617 ports of the same library, both directions, four models, four effort levels, and every combination of tests the agent gets to see.</span></div>
