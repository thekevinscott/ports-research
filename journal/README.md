# Journal

Lab notes for the porting experiment. Append-only. One entry per major event:
a run started or finished, a finding, a decision, a tool landed. UTC
timestamps.

One markdown file per entry, named `YYYY-MM-DDTHH-MMZ-<slug>.md` so the folder
sorts chronologically. Each file opens with a `# <UTC timestamp> <title>`
heading. Never edit an earlier entry; add a new file that corrects it.

Session handoffs in the session scratchpad or `/tmp` carry state between
sessions; this folder carries the record.
